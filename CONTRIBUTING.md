# Contributing

Thank you for your interest in contributing to LearnRust!

LearnRust is a curated collection of resources for learning Rust. As the Rust ecosystem has grown, there are now many books, courses, tutorials, videos, and other learning resources available.

We cannot include every resource, and we do not want to. The goal is to keep this list useful rather than simply making it larger.

Before submitting a new resource, please consider whether it adds something meaningful that is not already covered by the resources in the list.
 
## What we generally do not add

Please do not submit resources simply because they are about Rust.

We generally avoid adding:

- Resources that substantially duplicate existing material.
- Low-quality or poorly maintained tutorials.
- Very short articles that cover only basic information already available elsewhere.
- Content that is primarily promotional or intended to advertise a product or service.
- Resources that require a paid subscription, purchase, login, or other access restrictions.
- Content that is only available to members of a private community.
- Collections of links that do not provide substantial learning material themselves.

Since there are many high-quality free resources available, we prefer resources that can be accessed freely without requiring an account or payment.

## Before submitting a pull request

Please check the existing list first. If a resource covers the same topic as something already included, ask whether it offers a significant advantage or a different approach.

A good contribution should make the collection better, not simply longer.

If you are unsure whether a resource is a good fit, feel free to open an issue and discuss it before submitting a pull request.

## Quality matters

The purpose of LearnRust is to help people find useful resources for learning Rust. Adding a large number of mediocre or redundant resources makes it harder for learners to find the material that is actually useful.

For that reason, maintainers may decline a resource even if it is free and technically correct. The decision is based on whether it provides enough value to justify adding another entry to the collection.

Thank you for helping keep LearnRust useful and focused.
